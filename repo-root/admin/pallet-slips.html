작업 방식

  1. 원본 템플릿 Sheet1의 H열 값을 기준값으로 사용합니다.
  2. 업로드 파일 Sheet1의 P열 값과 비교합니다.
  3. 일치하는 값이 있으면 같은 업로드 행의 T열 값을 원본 파일의 같은 행 I열에 입력합니다.
  4. DB에는 저장하지 않고, 결과 파일을 Excel로 내려받습니다.
