작업 방식

  1. 저장된 엑셀 템플릿을 불러옵니다. 기본 위치는 /templates/coupang-entry-template.xlsx입니다.
  2. 쿠팡 시간표 이미지를 Claude Vision API로 분석해 센터·예약시간·물량·냉장·냉동을 JSON으로 추출합니다.
  3. 배차정보 텍스트는 기존 배차정보 파서 규칙에 맞춰 기사명·차량번호·연락처를 파싱합니다.
  4. 센터명 기준으로 시간표와 배차정보를 매칭하고, 확인 후 G6:G23 시간 행의 I/J, K/L... 영역에 입력합니다.

API 키는 보안상 코드에 저장하지 않고 이 화면에서만 입력합니다. 공용 PC에서는 작업 후 브라우저를 닫아주세요.
