CSV · Excel 파일 불러오기

파일당 최대 20MB, 대기열 최대 5개. 파일은 서버로 전송하지 않고 브라우저에서 읽습니다. XLSX는 선택한 시트의 값만 편집하며 서식·수식은 보존하지 않습니다. 수식은 파일에 저장된 계산 결과를 사용하고 결과가 없으면 빈칸으로 표시합니다. 날짜는 ISO 형식으로 표시합니다.

    셀을 두 번 클릭하거나 F2로 편집합니다. 셀 선택 후 Ctrl+V는 해당 위치부터 덮어씁니다. 열 제목을 클릭해 정렬하고, 제목 아래에서 필터링하세요. 제목 경계는 너비 조절, 제목 드래그는 순서 변경입니다. 다운로드는 현재 검색·필터·정렬과 열 순서를 반영합니다.
