일일 관리 엑셀 생성

대시보드

작업 방식

  1. 업로드한 일일 관리 Excel 템플릿의 Sheet1, 5행부터 B~R열을 편집 대상으로 불러옵니다.
  2. I열 차량 구분은 고정 → 광역 → 임시 순서를 유지합니다.
  3. 추가 기사 정보는 G열 담당자, H열 차량번호에 들어가며 선택한 구분의 마지막 행 아래에 삽입됩니다.
  4. 삽입 행은 지사/센터/날짜/운송사/기본값을 자동으로 채우고, J~M, P~R은 공란으로 둡니다.
  5. 결과는 DB 저장 없이 Excel 파일로만 다운로드합니다.
1
기준 템플릿 업로드
Sheet1 5행부터 B~R열을 읽습니다.
선택된 파일 없음
2
공통 자동 입력값
새로 추가되는 행과 날짜 일괄 적용에 사용합니다.
일
점검일자는 모든 행에 같은 “nn일” 형태로 적용할 수 있습니다.
3
기사/차량 추가
복붙 입력을 지원합니다. 기사명과 차량번호 조합은 한 행으로 유지됩니다.
기본 구분은 임시입니다. 필요한 경우 광역으로 바꾼 뒤 붙여넣으세요. 운송사는 항상 이안물류로 입력됩니다.
4 웹 편집 미리보기
순번 지사 센터명 점검일자 운송사 담당자 차량번호 구분 냉동온도 냉장온도 냉동 정상 냉장 정상 준수 구획분리 구획분리 사진 온도기록지 사진 비고 삭제
템플릿 Excel을 업로드하면 편집 표가 표시됩니다.
