대시보드

작업 방식

  1. 저장된 기본 템플릿을 먼저 자동으로 불러오고, 필요할 때만 업로드 파일로 임시 교체합니다.
  2. 템플릿은 Sheet1, 5행부터 B~R열을 편집 대상으로 불러옵니다.
  3. I열 차량 구분은 고정 → 광역 → 임시 순서를 유지합니다.
  4. 추가 기사 정보는 G열 담당자, H열 차량번호에 들어가며 선택한 구분의 마지막 행 아래에 삽입됩니다.
  5. 삽입 행은 지사/센터/날짜/운송사/기본값을 자동으로 채우고, J~M, P~R은 공란으로 둡니다.
  6. 결과는 DB 저장 없이 Excel 파일로만 다운로드합니다.
