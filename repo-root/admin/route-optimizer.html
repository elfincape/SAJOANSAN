로컬 배차 계산

Google OR-Tools가 내 PC에서 이동시간·물량·차량 적재량을 기준으로 센터 출발·복귀 코스를 계산합니다. 입력 데이터는 이 PC에서만 처리하며 업무 DB에 저장하지 않습니다.

프로젝트에서 npm run optimizer로 로컬 서버를 실행한 뒤, 실행 창의 연결 키를 입력하세요. 최초 연결 시 브라우저의 로컬 네트워크 접근 허용이 필요할 수 있습니다.

stops: 첫 지점은 센터 · minutes: 지점 간 분 단위 이동시간 행렬 · demands: 지점별 정수 물량(센터 0) · capacities: 차량별 정수 적재량 · seconds: 계산시간 1~30초. 물량과 적재량은 같은 단위를 사용하세요.

현재 계산은 납품 마감·하차시간·실시간 교통을 포함하지 않습니다. 확정 배차 전에 실제 조건을 확인하세요.
