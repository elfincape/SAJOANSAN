3 비교할 열 연결

연결한 모든 열의 값이 같은 행을 찾습니다. 예: 시트 1 A·B·C열 ↔ 시트 2 B·C·F열.

두 파일의 시트를 선택하면 비교 열을 연결할 수 있습니다.

기본은 실제 값으로 비교합니다. 숫자 1과 문자 “1”은 다릅니다. 표시값 비교는 서식·반올림이 적용된 문자열을 비교합니다. 모든 비교 열에 값이 있어야 조건을 충족하며, 0은 인정하고 빈칸·공백만 있는 값·오류 셀은 제외합니다.
