# 이안 문자 사진 저장 v0.4.0

선택 번호에서 이미 받은 사진을 **기간 전체 목록 확인 → 한 장씩 열어 저장 → OneDrive 업로드 확인 → 이번 휴대폰 저장본 삭제 → 다음 사진** 순서로 처리합니다. 공유창·호출 앱 신원 확인 흐름은 제거했습니다. 기존 카카오 앱과 관리허브는 변경하지 않습니다.

## 업데이트

기존 앱을 삭제하거나 데이터를 초기화하지 마세요. 로그인·번호·기간을 유지하는 같은 서명의 업데이트입니다.

```powershell
.\adb.exe install -r ".\ian-mms-collector-v0.4.0-debug.apk"
```

1. **화면 방식: 사진 전체 접근 허용**에서 사진을 **모두 허용**합니다. 선택한 사진만 허용하면 실행하지 않습니다.
2. **화면 방식: 저장본 삭제 권한**에서 미디어 관리 권한을 허용합니다. 이번 수집에서 새로 저장한 Download 사본을 정리하는 데 사용합니다.
3. **화면 방식: 접근성 설정**에서 이안 문자 사진 저장을 켭니다. 업데이트 후 연결이 끊겼다면 다시 켭니다.
4. OneDrive 연결 상태와 발신번호·시작일·종료일을 확인하고 **기간 전체 사진 수집 시작**을 누릅니다. 해당 대화의 사진이 모두 상대방에게 받은 것임을 확인합니다. 보낸 사진이 섞인 대화는 아직 지원하지 않습니다.
5. 삼성 메시지에서 해당 번호와 기간을 확인한 뒤 첨부 목록 전체를 먼저 순회합니다. 확정한 사진만 한 장씩 열고 다시 번호·날짜를 확인한 뒤 저장합니다. 처음 열린 임의 사진은 바로 저장하지 않습니다.
6. 각 저장 직전의 MediaStore ID 목록과 비교해 새 저장본을 찾습니다. OneDrive 전송 확인과 휴대폰 저장본 삭제 확인을 마친 후 다음 사진으로 이동합니다. 화면을 켜고 잠금을 풀어두며 다른 조작을 하지 마세요. 직접 잠그면 중단하며 화면 유지 한도는20분입니다.

공개 Microsoft 클라이언트 ID는 기존 `682488f9-cf2d-4d28-b4f4-75ba9d52e743`를 사용합니다. 새 Entra 설정이나 비밀 키는 필요하지 않습니다. 일반 MMS 직접 조회 버튼과 문자 읽기 권한은 별도 기존 기능입니다.

## 저장·삭제 범위

- 위치: `이안카카오/문자/발신번호/표시날짜_시간_<접수UUID>_01.jpg` 등. 사진 원본 바이트를 올리며 원격 JSON/TXT는 만들지 않습니다.
- 한국 시간 기준 시작일·종료일을 모두 포함합니다. 화면에 연도가 생략되므로 올해 기간만 지원합니다. 파일명에 적힌 촬영 날짜를 수신 날짜로 추측하지 않습니다.
- 사진당10MB, JPG·PNG·WEBP·GIF를 지원합니다. 같은 분의 동일 사진도 목록 위치와 바이트 등장 순번으로 각각 처리합니다. 재실행은 기존 원격 파일을 재확인합니다.
- 사용자 단말에서 확인한 저장 위치인 `Download/`, 소유 앱 `com.samsung.android.messaging`, 이미지 등록을 MediaStore Files 목록에서 확인합니다. 저장 직전 존재하던 항목은 pending 상태까지 제외합니다. 새 파일이 없거나 여러 개이면 추측하지 않고 중단합니다.
- 새 ID·세대·크기·수정 시각·MediaStore 버전과 내용 해시를 접수에 기록합니다. 업로드 표시만으로 삭제하지 않고 원격 계정·파일·크기를 재확인하며, 로컬 저장본 해시·등록 정보도 다시 확인합니다. 이후 그 새 사본만 삭제 요청하고 실제로 사라졌는지 확인합니다.
- **원본 문자, MMS/RCS 첨부, 기존 Download·갤러리 사진은 삭제하지 않습니다.** 앱 임시 사본은 업로드 확인 후 정리합니다. 실패/중지 시 미전송 임시 파일과 삭제 미확인 저장본은 유지합니다. 재시작은 기록된 대기 전송·새 저장본 정리를 먼저 재시도합니다.
- MediaStore가 재구성되거나 저장본 내용이 바뀌면 삭제하지 않습니다. 기록되기 전에 앱이 종료된 새 사본은 안전상 자동 삭제하지 못할 수 있습니다.

## 검증 상태

저장소 밖 임시 검사에서 전체 목록 반복, 날짜 양끝 포함·범위 밖 제외, 번호 확인, 같은 분의 여러 사진, 저장 전 스냅샷, 기존/pending 항목 제외, 신규 여러 장·저장소 버전 변경 거부, 원격 실패·내용 변경·권한 거부·취소 시 삭제 금지, 새 사본 삭제 확인·재실행을 검증했습니다. 공유 버튼이 호출되면 실패하도록 검사했습니다. Android assemble/lint와 기존 웹 build를 실행합니다. 저장소에는 테스트 파일을 추가하지 않습니다.

이는 모의 Android 화면·미디어 저장소·전송 검사입니다. 실제 단말에서 Samsung 저장본 등록, OneDrive 업로드, 미디어 관리 권한에 따른 삭제, 전체 기간 연속 완료는 설치 후 확인해야 합니다. 화면 꺼짐 실행은 지원한다고 보장하지 않습니다.
