# 엑셀 시트 비교

관리 허브의 **엑셀 시트 비교** 메뉴(`/admin/excel-compare.html`)에서 사용합니다.
기존 editor 이상 권한, 센터 선택, 설정의 기능 표시 스위치를 적용합니다.

1. 파일 두 개를 선택합니다. 같은 파일을 양쪽에 선택해 서로 다른 시트를 비교할 수도 있습니다.
2. 각 파일의 시트와 제목 행을 선택합니다. 제목이 없으면 0, 제목이 3행이면 3을 입력합니다.
3. 비교 열을 쌍으로 연결합니다. 예를 들어 시트 1 A/B/C열과 시트 2 B/C/F열을 세 쌍으로 지정합니다.
4. 값 가져오기 모드에서는 상대 시트에서 가져올 열을 여러 개 선택합니다. 한쪽 방향만 선택해도 됩니다.
   존재 여부만 확인 모드는 가져올 열 없이 TRUE/FALSE를 표시합니다.
5. 비교 실행 후 각 시트의 조건 충족 행수, TRUE/FALSE 행수, 조건 미충족 및 중복 관련 행수를 확인합니다.
6. 결과 Excel에는 비교 요약, 시트1 결과, 시트2 결과가 포함됩니다. 미리보기 필터와 무관하게 전체 결과를 다운로드합니다.

## 비교 규칙

- 비교 쌍 **모두**의 값이 같아야 같은 키입니다. 행 순서나 실제 열 위치는 같을 필요가 없습니다.
- 모든 비교 열에 값이 있는 행만 조건을 충족합니다. 빈칸, 공백만 있는 셀, 오류, 계산값 없는 수식은 조건 미충족입니다.
- 숫자 0과 불리언 FALSE는 값입니다. 앞뒤 공백 무시가 기본이며 대소문자 무시는 선택 사항입니다.
- 기본은 실제 셀 값으로 비교합니다. 숫자·문자·불리언 타입을 구분하며 표시 서식이나 반올림으로 다른 숫자를 같다고 처리하지 않습니다.
  숫자 1과 문자 "1"을 같은 표시로 비교하려면 표시값 모드를 선택합니다.
  표시값 모드에서는 `001`과 `1`, `1,000`과 `1000`, 서로 다른 날짜 표시 형식이 다릅니다.
  1900/1904 날짜 기준은 실제 날짜에 맞춰 보정합니다.
- 복합 키는 열 순서를 유지하는 튜플로 비교합니다. 구분자가 포함된 값도 충돌하지 않습니다.
- 기본 중복 처리는 등장 순서대로 1:1 연결입니다. 상대 행이 부족하면 추출값은 빈칸이고 상태로 표시합니다.
  첫 행 재사용 또는 양쪽 모두 유일한 키만 추출하는 옵션도 제공합니다.
- TRUE/FALSE는 상대 시트에 같은 키가 있는지를 나타냅니다. 1:1 연결에서 상대 행이 부족해도 존재하면 TRUE입니다.
  조건 미충족 행은 존재 여부를 빈칸으로 표시하며 FALSE 집계에 포함하지 않습니다.
- 데이터가 있는 원본 행의 순서와 Excel 행 번호를 유지합니다. 완전히 빈 행은 생략합니다.
- 수식은 파일에 저장된 계산값으로 비교하고 값만 내보냅니다. 원본 통합문서를 변경하지 않습니다.
  결과는 새 통합문서이며 원본 서식, 수식, 하이퍼링크, 매크로를 복제하지 않습니다.
- 지원 파일: xlsx/xls/xlsm/xlsb, 파일당 20MB. 시트당 데이터 최대 10만 행, 256열, 200만 셀.
  미리보기는 페이지당 50행입니다. 파일 내용은 서버나 DB로 전송하지 않습니다.

## 검증

기존 도구와 같은 SheetJS 0.18.5 번들을 사용합니다. 로컬에 `xlsx`를 설치하거나 `XLSX_TEST_MODULE`을 해당 번들 경로로 지정합니다.

```sh
node --test tests/*.test.mjs
```

브라우저 통합 검사는 기본 실행에서 건너뜁니다. Playwright와 SheetJS가 설치된 환경에서 아래 환경변수를 지정해 실행합니다.

```sh
RUN_BROWSER_TESTS=1 node --test tests/excel-compare-browser.test.mjs
```

필요 시 `PLAYWRIGHT_TEST_MODULE`, `XLSX_TEST_MODULE`, `BROWSER_EXECUTABLE`을 지정합니다.
`BROWSER_TEST_OUTPUT`은 선택적인 스크린샷 저장 폴더입니다. 서버는 127.0.0.1의 임시 포트만 사용합니다.
인증은 테스트용 프로필로 대체하며 실제 인증 파일은 수정하지 않습니다. 센터 모듈은 실제 코드를 검사합니다.

검증 범위: 다중 열 위치 변경, 행 재정렬, 양방향 추출, 중복 처리, 빈칸/0/FALSE/오류,
표시 형식, 제목 행, Excel 저장·재열기와 불리언 타입, 수식 문자열 안전성, 1904 날짜, 10만 행,
브라우저 업로드·다운로드, 결과 필터, 변경 시 결과 무효화, 모바일 너비, 권한 차단.
