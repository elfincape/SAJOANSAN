# 톡클라우드 사진 정리

SAJOANSAN과 별도로 실행하는 Python·Playwright 웹앱입니다. OpenAI API와 업무 DB를 사용하지 않습니다.

카카오 계정 연결 → 필요시 모바일 승인 → 방 선택 → 날짜 지정 → 사진 삭제 순서로 사용합니다. 방은 원래 목록 순서로 20개씩 표시하며, 사진만 휴지통으로 이동합니다. 휴지통 전체 비우기는 기존 휴지통 전체를 영구 삭제하므로 별도 확인을 받습니다.

서버는 한 계정씩 처리합니다. 다른 사용자는 연결 가능 여부를 자동 확인하며 기다립니다. 연결 종료 또는 유휴 10분 후 브라우저 세션이 폐기됩니다. 비밀번호·쿠키를 파일에 저장하지 않습니다. 보안문제가 나오면 웹에 표시된 카카오 화면에서 사용자가 직접 풉니다. 해당 화면과 입력은 현재 세션 메모리에서만 처리합니다.

배포: 파일을 `/opt/talkcloud`에 배치하고 `deploy/talkcloud.service`의 `PUBLIC_ORIGIN`, `deploy/nginx.conf`의 주소·인증서 경로를 환경에 맞게 설정합니다. Ubuntu에서 `sh deploy/install.sh` 실행 후 nginx 설정을 적용합니다. 기존 서비스의 설정을 덮어쓰지 마세요. HTTPS 및 인증서 자동 갱신이 필요합니다.

카카오 웹 UI 변경 시 선택자 점검이 필요합니다. 전체 파일 수·사진 날짜·선택 방·선택 개수가 맞지 않으면 삭제를 중단합니다. 실제 운영 환경의 로그인과 모바일 승인 여부는 계정별 확인이 필요합니다.
