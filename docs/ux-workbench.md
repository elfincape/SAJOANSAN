# 업무 화면 디자인·조작 확장

기준 커밋: `d15b67f`. 기존 React/TypeScript 앱과 설치된 AG Grid·KBAR·Lenis를 재사용했습니다. 배차 계산·Supabase 저장 API·서버 권한 정책·기존 HTML/JS/CSS 원본과 루트 메일 API는 변경하지 않습니다.

## 실제 업무 기능

- **저장한 보기:** 차량·기사·운수사·납품처·코스·대시보드에서 검색과 필터를 이름으로 저장합니다. 대시보드는 정렬·그룹·열 구성을, 코스는 AG Grid 상세 필터도 포함합니다. 현재 계정·센터·브라우저별 최대 12개이며 다른 기기에 동기화되지 않습니다. 삭제 취소를 제공합니다.
- **문맥형 선택 작업바:** 기준정보 네 목록과 코스의 체크박스 선택 시 표시합니다. 현재 필터에서 보이는 선택만 내보내고, 내보내기 권한을 확인합니다. CSV의 수식 시작 문자는 이스케이프합니다. 기존 개별 검증 없이 일괄 수정·삭제하지 않습니다.
- **목록·편집 패널:** 차량·기사·운수사·납품처에서 마우스 드래그와 방향키/Home/End로 너비를 조절하고 접을 수 있습니다. 접어도 입력은 유지되며 좁은 화면은 세로 배치합니다.
- **인라인 초안:** 선택한 차량의 톤수를 표에서 수정합니다. 상세 폼과 같은 초안이며 Enter로 정리, Escape로 편집 시작 전 초안을 복원합니다. 실제 반영은 기존 저장 버튼을 사용합니다.
- **변경 전후 확인:** 기준정보 편집, 포털 업무, 배차 변경에 원래 값과 초안을 표시합니다. 서버 저장·배차 유효성 검사 경로는 유지합니다.
- **문맥형 KBAR:** Ctrl/⌘ K에 현재 화면의 검색·필터·신규·보기·선택 내보내기, 배차의 되돌리기·다시 실행·저장 등을 가능한 상태에서만 노출합니다. 다른 모달이 열리면 진입을 막고, 명령 실행은 팔레트를 닫은 뒤 진행합니다.
- **배차 보드:** 기존 상세 표를 기본으로 유지하며 차량별 착지 카드 보기로 전환할 수 있습니다. 확인된 실제 상차한도·초과·한도 미확인, 분할 원본과 수량을 표시합니다. 카드 순서 변경과 이동은 기존 검증 절차를 사용합니다.
- **지도 연계:** 카드를 선택한 뒤 지도를 명시적으로 열면 저장된 주소의 유일한 유효 WGS84 좌표로 OpenStreetMap을 표시합니다. 좌표가 없거나 충돌하면 주소 확인 링크를 제공합니다. 주행 경로나 예상 시간을 만들지 않으며 지도는 외부 서비스입니다.
- **배차 되돌리기:** 저장 전 로컬 편집을 최대 20단계 되돌리고 다시 실행합니다. 저장·파일·날짜·새 가배차·설정·자료 변경 경계에서는 기록을 초기화합니다. 서버에 저장한 작업을 취소하는 기능은 아닙니다.
- **포털 버전 확인:** 버전과 조회 시각은 평상시에 표시하지 않고, 실제 다른 변경이 있을 때만 최신 내용 안내를 표시합니다. 명시적 확인과 화면 복귀 시 제한된 조회를 사용하며 실시간 접속자·자동 동기화를 추정하지 않습니다. 새 버전을 불러오기 전 미저장 입력 폐기를 확인하고, 목록 갱신 중에는 기존 초안의 기준 버전을 유지합니다.
- **로딩·결과:** 첫 조회는 스켈레톤, 새로고침은 기존 목록 유지, 포털은 실제 조회 시각과 브라우저 오프라인 상태를 표시합니다. 토스트는 상단 도구를 가리지 않도록 우측 하단에 둡니다.

초안과 배차 실행 취소는 메모리 상태이며 새로고침 후 복원을 보장하지 않습니다. 사용자·센터·업무 권한은 기존 판정을 재사용하며 클라이언트 표시를 서버 인증·RLS의 대체로 사용하지 않습니다.

## 검증

모의 인증·가상 업무 자료로 브라우저를 검증합니다. 운영 자료 저장·메일 수집·실제 가배차 요청을 실행하지 않습니다. 33개 진입 화면의 두 테마와 1440px/390px(132개), 포털 내부 화면, 선택·호버·드래그·모달·키보드·모션 감소, 기존 CRUD·권한·배차 검사와 새 업무 기능 검사를 함께 수행합니다. JEV의 메뉴 탐색은 실제 도착 URL과 제목으로 검증하고, 모델의 DONE만으로 통과 처리하지 않습니다. 자동 대비 검사는 이미지 속 글자나 모든 실제 데이터를 포함한 접근성 인증은 아닙니다.

완료 확인: TypeScript/Vite 빌드 통과(기존 대형 번들 경고 유지), 기본 132개 화면·포털 내부 화면·기존 18개 상태와 새 작업 UI 16개 조합에서 검사 대상 대비 미달/가로 넘침/브라우저 예외 없음. 기준정보 저장 실패·입력 보존·재시도·센터 범위 삭제, AG Grid, 권한/기능 표시, 배차 기존 검사와 보드·실행 취소, 포털 버전/초안, 저장한 보기·CSV·패널·커맨드·인라인 초안 검사를 통과했습니다. 독립 코드 검토에서 확인한 접힌 편집 패널 재열기 문제를 수정하고 네 화면의 신규·행·선택 상세 동작을 다시 확인했습니다. Impeccable 정적 검사 결과는 `[]`입니다.

JEV는 가상 자료가 있는 로컬 차량 관리 화면에서 코스 관리 메뉴를 선택했고 7회 관찰 루프 안에 코스 목록에 도착했습니다. 실제 도착 URL `/admin/routes.html?center=ansan`과 문서 제목으로 확인했습니다. 초기 브라우저 세션 연결 실패는 운영 웹 결함으로 집계하지 않았으며 전용 프로필·런타임으로 분리해 해결했습니다.
