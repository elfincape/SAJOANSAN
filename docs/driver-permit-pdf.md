# 인허가 서류 PDF 취합

기사관리에서 8종 사진이 저장되어 있으면 `인허가 PDF 저장`을 사용할 수 있습니다. 순서는 식품운반업 앞/뒤, 축산물운반업 앞/뒤, 화물운송사자격증, 차량등록증, 신분증, 보건증입니다. 각 사진을 A4 한 페이지에 비율 유지·여백 포함하여 배치하며 가로 사진은 가로 A4로 저장합니다.

브라우저가 저장된 사진을 순서대로 읽고 회전 정보를 반영해 JPEG로 변환합니다(긴 변 최대 3508px, 품질 94%). 서버가 저장된 8장 버전을 다시 확인하고 PDF를 생성합니다. 변환 중 사진이 변경되거나 8장이 준비되지 않으면 저장하지 않습니다.

파일명은 `센터_차량번호_기사명_운수사_인허가취합.pdf`이며 001/002는 안산/평택입니다. 지정한 PDF 폴더 바로 아래 저장하고 동일 기사의 동명 PDF는 갱신합니다. 다른 파일과 이름이 충돌하면 덮어쓰지 않습니다. 사진의 후속 변경·삭제가 이미 저장한 PDF를 자동 갱신하지 않으므로 다시 PDF 저장을 실행해야 합니다.

관리자는 기사관리의 `PDF 저장 폴더 설정`에 공유 링크를 최초 1회 입력합니다. 공유 링크는 저장소에 커밋하지 않습니다. 서버에서 소유자·폴더를 확인한 뒤 서버 전용 onedrive_settings.folders.permit_pdf에 식별자만 보관합니다. DB 마이그레이션 onedrive-pdf.sql은 배포 워크플로가 적용합니다. driver_document_pdfs는 서버 전용 저장 기록입니다.

테스트: node tests/onedrive-pdf.test.mjs 및 node tests/driver-documents.test.mjs. 실제 PDF 생성기는 pdf-lib 1.17.1을 사용합니다.
