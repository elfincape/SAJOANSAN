# 화면 흐름과 탐색 정리

기준 커밋 `1afefee`. 화면 밀림, 불필요한 상태 정보, 중간 로딩 화면, 팝업 모션과 메뉴 분류를 수정했습니다. 업무 저장·배차 계산·서버 권한·루트 메일 API는 유지합니다.

## 화면 밀림·상태 표시

센터 업무의 일·주·월 조회는 `refresh()`가 본문 알림을 추가·제거하며 필터를 약 67px 움직이고 있었습니다. 조회 중에는 기존 목록과 필터를 유지하고 새로고침 버튼 안의 상태로 표시합니다. 목록 조회 성공 시각·평상시 서버 버전 표시·상단 초기 조회 안내를 제거했습니다. 저장 결과와 오류는 본문 높이를 바꾸지 않는 닫을 수 있는 안내로 표시합니다.

업무 상세는 평상시에 버전·마지막 조회 시각을 표시하지 않습니다. 실제 최신 내용이 달라졌을 때만 “업무 내용이 변경되었습니다”와 최신 내용 불러오기를 표시합니다. 미저장 입력을 버리기 전 확인과 서버의 기존 버전 검사는 유지합니다. 열린 팝업의 실제 저장 오류는 팝업 안에서도 표시해 입력과 처리 버튼을 가리지 않도록 했습니다.

변경 이력의 조건 조회도 응답을 기다리는 동안 기존 행을 유지합니다. 로딩 문구가 표 아래에 추가되어 높이가 바뀌지 않으며, 응답을 기다리는 기존 행은 편집 상세를 열지 않습니다.

## 페이지 이동·로고

포털·관리 허브·대시보드와 코스·차량·운수사·납품처·설정·사용자·이력 화면 사이에서는 다음 화면 코드와 새로 확인한 로그인·권한이 준비될 때까지 현재 화면을 유지합니다. 기존 주소·센터 파라미터·직접 접근·새로고침은 유지합니다. 준비 중 편집은 잠시 막고 미저장·처리 중·업로드 보호를 확인하며, 오류가 나면 원래 화면과 조작을 복원합니다. 통상 이동에서는 문구 팝업 대신 지연 후 얇은 진행 표시만 나타납니다.

기사 PDF·배차·용차·서류 변환 등 문서 수명주기와 업로드 보호가 별도로 있는 도구는 기존 문서 이동을 유지합니다. 모든 화면을 새 라우터로 재작성하지 않았습니다. 화면 간 준비 이동은 위 검증된 범위에 한정하고, 나머지 기능은 기존 처리 순서를 유지합니다.

이동 후 로고 테두리는 사이드바의 비모달 `dialog.show()`가 첫 링크에 자동 포커스를 주면서 생겼습니다. 로고 링크 대신 탐색 컨테이너를 초기 포커스 대상으로 정리하고 비모달 컨테이너 자체에는 외곽선을 표시하지 않습니다. Tab으로 실제 링크·버튼을 선택했을 때의 포커스 표시는 유지합니다.

포털에서 쓰던 과거 운영 화면의 전역 스타일 참조를 제거하고 포털 스타일을 포털 범위에 한정했습니다. 대시보드의 전체 문서 높이·스크롤 설정도 대시보드 범위에 한정해, 여러 영역을 오간 뒤 다른 화면의 스크롤을 막지 않습니다.

## 팝업 모션

업무 팝업은 오른쪽 화면 밖에서 왼쪽으로 360ms 동안 진입합니다. 같은 시간에 배경 블러가 0→5px로 증가하며 본문 글자는 흐리게 만들지 않습니다. 닫기는 같은 방향의 역동작으로 처리하고 닫기 버튼·Escape·배경 클릭이 같은 경로를 사용합니다. 저장 중 닫기 금지·입력 유지·이전 포커스 복귀를 유지합니다. 모션 감소·대비 강화·투명도 감소 설정에는 별도 처리를 적용합니다. `@starting-style` 미지원 브라우저는 최종 상태를 바로 표시합니다.

## 허브·분류

목록의 처음 몇 개를 잘라 보여주던 “업무 바로 시작”, “파일 작업”, 센터·역할 요약 벤토를 제거했습니다. 권한이 있는 도구를 분류별로 한 번씩 표시하고 검색·분류 필터를 유지합니다.

제브에 실제 기능 이름과 설명을 제공해 4/5/6분류 후보를 비교하고, 선택된 5분류로 개별 기능을 검토했습니다. Notion 연동은 실제 관리자 연결 설정이라는 코드 근거를 보충해 다시 판단했습니다. 모델의 선택은 실제 기능과 대조했으며 모델 점수를 실제 사용자 정확도처럼 사용하지 않습니다.

| 분류 | 주요 기능 |
| --- | --- |
| 배차·운행 | 가배차, 배차 요청·파서, 용차, 이배송, 거리·하불 계산 |
| 운송 정보 관리 | 코스, 납품처, 기사, 차량, 운수사 |
| 센터 일상 업무 | 업무 포털, 1탑2실 작업·양식, 쿠팡 입문확인, 파레트 전표 |
| 문서·자료 | PDF·사진 변환, 엑셀 비교, 코스표 내려받기, CSV 가져오기 |
| 사용자·환경 설정 | 사용자, 권한, 변경 이력, 연동, 표시 설정 |

같은 `app/src/domain/feature-catalog.ts`를 허브·사이드바·설정·빠른 이동에서 사용합니다. 분류만으로 열람·수정 권한을 새로 부여하지 않습니다.

## 검증 범위

모의 인증·가상 자료로 지연된 일·주·월 조회의 필터 위치, 미저장 입력·업로드 보호, 버전 충돌 시 입력 유지/폐기 확인, 팝업의 프레임별 위치·블러·글자 필터, 실제 오류 표시, 테마·반응형·키보드 포커스를 검사합니다. 제브의 실제 메뉴 이동은 도착 URL과 제목으로 확인합니다. 배포 후 공개 주소·로그인·정적 자산·메일 API의 읽기 전용 경로를 확인하며 실제 고객 자료·운영 저장·OneDrive 업로드는 실행하지 않습니다.

Impeccable 정적 검사에서 기간을 넘어 이어지는 일정의 좌·우 연결 표시 두 곳을 장식 테두리로 탐지했습니다. 두 규칙은 기존 커밋에도 존재하며 일정 연결 의미를 유지하기 위해 그대로 두었습니다. 나머지 새 구성은 정적 검사와 실제 브라우저 검토를 함께 적용했습니다. 검사 스크립트·이미지·제브 응답은 저장소 밖에 보관합니다.

통합 검증 결과: TypeScript/Vite 빌드 통과(기존 대형 번들 경고 유지), 33개 진입 화면의 밝은/어두운 테마와 데스크톱·모바일 132개 조합에서 검사 대상 대비 미달·가로 넘침 없음. 최종 코드를 고정한 모바일 재검사에서는 브라우저 예외도 없었습니다. 기존 선택·입력·모달·파일 dragover 등 18개 상태, 다섯 관리 화면의 실패 후 입력 보존·재시도·센터 범위 삭제, 역할/센터/기능 표시, 지연된 조회·내부 이동과 업로드 보호 검사를 통과했습니다. 독립 변경 리뷰에서 확인한 이동 준비 중 편집·연속 뒤로가기·업로드 가드 문제를 수정하고 다시 검증했습니다.

제브는 새 허브에서 차량 관리 기능을 찾아 4회 관찰 루프 안에 `/admin/vehicles.html?center=ansan`에 도착했습니다. 실제 URL과 화면 제목으로 통과를 확인했습니다. 모델의 판단값을 사용자 발생률이나 배차 품질의 근거로 사용하지 않습니다.
