# 관리허브–노션 연결

센터별 `납품처 정보 확인` 페이지에서 **코스 / 납품처 / 운수사 / 기사** 탭을 전환합니다. 안산은 센터 코드 `001`, 평택은 `002`로 구분합니다.

노션의 업무 기록이나 댓글에서 `@코스명`, `@납품처명`을 입력하고 해당 페이지를 선택하면 연결된 정보를 열 수 있습니다. 같은 납품처에 여러 코스가 있으면 코스별 운수사·주기사·보조기사를 각각 표시합니다.

기본 정보는 페이지의 속성에서 수정하고, 업무 메모는 본문이나 댓글에 작성합니다. 자동으로 생성되는 ‘연결 정보 · 자동 갱신’ 영역 밖의 본문과 댓글은 보존됩니다. 자동 영역을 직접 수정하면 그 내용을 덮어쓰지 않고 수동 확인 대상으로 남깁니다.

관리허브의 운수사·기사·코스 화면에는 관리자용 **노션 동기화** 버튼이 있습니다. 웹 저장 후 해당 항목의 연동을 시도하며, 전체 추가·수정은 기존 납품처 정기 작업에 이어 관계 자료를 처리합니다. 정기 작업의 설정 주기는 15분이며 실제 실행 시각은 GitHub Actions의 대기 상황에 따라 달라질 수 있습니다.

운수사와 담당 기사의 배정은 기존 웹처럼 **코스를 기준으로** 관리합니다. 납품처의 담당 정보는 코스에서 가져옵니다. 차량의 번호·톤수와 납품 순서·도착시간은 기존 웹 자료를 정보 영역에 표시합니다.

양쪽에서 서로 다른 항목을 바꾸면 변경을 합치고, 같은 항목을 다르게 바꾸면 ‘충돌 확인’으로 남깁니다. 다른 센터의 관계를 연결하거나 연결된 자료를 삭제한 경우 자동으로 재생성하지 않습니다.
