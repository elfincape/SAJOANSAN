# 업무 화면 UI·UX 재개선

2026-10-16. PC 중심, 모바일 조회·처리. 기존 데이터·권한·업무 동작 보존.

- 포털의 밝은 고정 표면과 공통 어두운 변수가 충돌하던 문제를 밝은 semantic tokens로 통일했다. 내비게이션에만 남색을 사용한다.
- 관리 허브는 기존 메뉴를 이름·설명으로 검색하고 업무/기준정보/파일/시스템으로 좁힌다. 권한 관리 카드와 비공개 기능 조건을 보존한다. 검색 숨김과 권한 차단을 별도로 기록하여 권한 observer가 결과를 다시 노출하지 않도록 한다.
- 코스표는 검색·보기 전환·결과 수를 앞에 두고 기존 상세 필터를 disclosure에 배치한다. 0건 상태에서 기존 초기화 동작을 바로 실행할 수 있다. 첫 열 고정과 행 대비를 정리한다.
- 입력, 버튼, 표, 패널, 포커스와 상태 색을 통일한다. 기존 달력의 오늘 강조와 기간 표시 수정은 유지한다. 코스 관리 AG Grid도 밝은 색으로 맞춘다.
- 외부 Tailwind CDN 실패 시 거대한 SVG와 깨진 배치를 재현하여 유틸리티를 기존 Vite 빌드에 포함했다. 포털에는 새 전역 reset을 적용하지 않는다.

디자인 진단·허브 구현·독립 화면 검수를 별도 에이전트와 나누었다. Impeccable/Operate와 UI UX Pro Max의 내부 업무 UI 지침, shadcn/21st.dev의 검색·내비게이션 패턴을 참고했다. React나 별도 디자인 서비스로 이전하지 않는다.

검증 범위: 테스트 계정 응답으로 31개 화면을 PC 1440px/모바일 390px에서 방문하여 문서 가로 넘침을 점검했다. 제한 권한은 실제 화면 열람을 막으므로 이를 정상 데이터 검증으로 계산하지 않는다. 전체 열람 응답에서도 소유자 전용 기능, route ID가 필요한 편집 화면과 설정 전용 권한은 별도 제한으로 남는다. CRUD 저장, OneDrive 다운로드, 실제 업무 데이터 정확성은 모의 응답 검사 범위에 포함하지 않는다.
