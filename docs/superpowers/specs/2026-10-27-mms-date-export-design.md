# 기간 지정 MMS 사진 저장

요청: 특정 발신번호의 삼성 메시지 사진을 시작일~종료일로 지정해 OneDrive에 원본 파일로 저장한다. 시작/종료일은 한국 시간 기준 모두 포함한다. 번호는 앱에서 입력/수정한다. 문자 원본은 보존한다.

기존 OneDrive 인증·큐·원본 업로드 코드를 재사용하는 별도 Android 모듈을 만든다. 이전 앱의 서명키는 현재 환경에 없어 패키지를 분리하여 기존 카카오 앱과 데이터를 보존한다. 새 앱에 한 번 로그인이 필요하다. MMS ContentProvider의 수신함/완료된 MMS만 조회하고 FROM 주소를 정규화하여 정확히 일치시킨다. 해외표기 +82는 국내 0 표기로 변환하고 뒷자리 비교는 하지 않는다. RCS·다운로드되지 않은 MMS·삼성 전용 비공개 저장소는 지원을 보장하지 않는다.

화면 자동화/알림은 과거 날짜 조회 및 실제 원본 확보에 적합하지 않아 사용하지 않는다. READ_SMS 런타임 권한을 사용하며 OS/설치 프로그램이 제한하면 상태로 알린다. 기본 문자 앱으로 바꾸거나 루팅하지 않는다. 권한이 거부되면 수집 성공으로 표시하지 않는다.

저장: 이안카카오/문자/<번호>/<수신시각 KST>_<안정적인 UUID>_01.jpg 등. JPG/PNG/WEBP/GIF 실제 바이트를 보존한다. 파일당 10MB, MMS당 30장 제한을 명시한다. 원본 문자와 첨부는 삭제하지 않고 업로드한 앱 임시 사본만 정리한다. 겹치는 날짜 재실행 시 같은 MMS 사진/계정으로 만든 안정적인 접수 ID를 사용해 중복을 막는다. 이미지 파일 외 JSON/TXT는 원격에 추가하지 않는다.

서비스는 사용자가 기간 저장 버튼을 눌렀을 때만 실행하며 취소/진행 건수/오류를 표시한다. 실행 중 앱을 닫아도 foreground service가 처리하고, 폰 재부팅 후 자동 재실행은 하지 않는다. 전송 실패는 큐에 유지하며 다음 저장 실행에서 재시도한다. 다른 번호·기간의 미전송 큐를 몰래 처리하지 않도록 현재 조건의 접수만 재시도한다.

실기기 MMS 조회/권한과 OneDrive 실제 저장은 사용자 단말에서 별도 확인한다. 원격 개발 환경은 단말 MMS에 연결되어 있지 않다.
