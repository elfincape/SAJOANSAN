# 네이버 코스별 실제 화면 캡처
사용자 승인 범위: 엑셀 다중 코스, 차고지→센터→납품처→차고지의 입력 순서 유지. 사용자가 2026-10-28 네이버 한도 내 코스만 제작하도록 지시했다.

기존 네이버 최단거리 화면에 코스 캡처 탭을 추가한다. 엑셀 한 행은 한 코스이며 코스명/차고지/센터/납품처1~4/복귀차고지 주소를 받는다. 센터 포함 경유지 최대 5개, 같은 차고지로 복귀, 최대 100코스/파일 10MB. 빈 행 무시, 오류 행은 원본 행 번호로 표시하며 실행 전 수정이 필요하다. 주소가 중복된 별도 코스도 결과를 각각 생성한다.

접근: API 거리값만으로 화면을 재현하면 실제 지도 캡처 요건을 만족하지 않는다. 별도 자동화 서비스 대신 기존 Playwright 워커와 naver_browser_jobs를 확장한다. kind로 거리 조회와 캡처를 구분하며 기존 데이터/권한을 유지한다. 지도 결과의 거리우선 카드 존재와 모든 방문지 입력을 확인한 후 실제 패널 PNG를 저장한다. 입력 순서를 최적화하거나 한도 초과 코스를 분할하지 않는다.

비공개 Storage bucket에 owner/job/course 경로로 저장한다. 작업 상태에는 이미지 경로만 보관한다. 조회 권한은 작업 소유자와 센터 납품처 열람 권한을 모두 요구한다. PNG 미리보기/개별 저장, ZIP 일괄 저장, 코스당 PDF 한 페이지 출력. 실패 코스는 이유 표시, 실패 코스 재시도 제공. 취소/화면 복원, 진행 수 표시. 네이버 차단 시 성공처럼 표시하지 않는다. Ego Lite 도구는 이 세션에 노출되지 않았으므로 기존 Playwright 사용.
