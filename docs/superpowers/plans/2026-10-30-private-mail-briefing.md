## 운영 적용 보류와 남은 실검증

사용자의 재개 승인 후 Notes 연결용 최소 SQL만 정상 적용했다. 마이그레이션은 `20261030123236 / private_mail_notes_oauth`이며, 두 열과 전용 완료 함수의 존재, 기존 파일 함수의 `purpose='files'` 분리 및 기존 실행 권한 유지를 읽기 조회로 확인했다. 자동분석·필터·예약 SQL은 여전히 미적용이며 자동화를 활성화하지 않았다. Microsoft Notes.ReadWrite 연결, 서버 인증 설정 일치, 스케줄러 등록, 실제 50MB 호스팅 메모리·시간 제한은 검증 전이다. 사용자 실행 중인 수집 작업은 변경하지 않았다.

운영 `main`의 추가 변경 `2bf0d09`(기존 디자인 문서·CSS)을 보존해 병합했다. 병합 후 관련 검사 21개 파일, 앱 빌드, 소유자 전용·일일정리 모의 브라우저 검사를 다시 통과했다. 이번 배포의 우선 검증 대상은 사용자가 직접 동의할 수 있는 Notes 연결 화면이다. 실제 분석·OneNote 기록·예약 수집이 검증된 것으로 간주하지 않는다.

사진 원본은 보존한다. JPEG/PNG는 OneNote에 삽입하고 WebP는 분석 후 삽입 확인 필요 상태로 남긴다. 크기·개수 한도를 넘는 사진은 조용히 생략하지 않고 확인 상태로 둔다. 사진 PATCH 응답이 유실되어 실제 반영 여부를 판단하지 못하면 중복 삽입 대신 확인 상태로 중단한다. 이 예외의 무인 복구는 아직 보장하지 않는다.

## 사용자 요청에 따른 자동화 활성화

- 사용자가 동의·읽음확인 체크박스 제거와 실제 자동화를 명시 요청했다. 입력 폼은 제거하고 상태·일시정지/재개·현재 묶음 중지만 남겼다. 승인 근거는 서버 설정에 기록하며 읽음 상태를 확인했다고 위조하지 않는다.
- `20261030133150 / private_mail_automation_runtime`으로 기존 테이블의 분석·필터·작업 상태와 1분 복구 cron을 설치했다. 신규 수집 사이클은 3시간, 잔여 청크는 즉시 이어간다. 배포 검증 전까지 실행은 꺼둔 상태로 설치했다.
- 장기 메일키나 Vault 복사 없이, 서버 DB가 발급한 작업별 10분 capability를 Node→Edge에서 대상·소유자·만료·lease와 함께 매 요청 검증한다. mailbox 상태에는 해시만 저장하며, 원문 capability는 pg_net 전송 큐에 일시 존재한다.
- 인증→claim 경합에는 최초 인증 기준 60초 유예를 두고, 검증된 완료 RPC는 기존 capability를 정리해 다음 청크를 즉시 발급한다.
- 실제 Supabase transport 큐는 플랫폼 소유라 프로젝트 postgres의 ACL 축소가 적용되지 않았다. 기존 권한은 확대하지 않았다. REST `net` 요청은 실제 406/PGRST106으로 차단되고 GraphQL은 확장 미설치로 사용할 수 없음을 확인했다. anon/authenticated는 NOLOGIN이며 신규 인증 RPC는 service_role만 실행한다. 이 API 경계를 유지해야 한다.
- 관련 로컬 검사 22개 파일, 앱 빌드, 체크박스 없는 화면·일시정지/재개 모의 브라우저 검사를 통과했다. 실제 수집·분석·OneNote 기록은 배포 후 따로 검증한다.

- `3966e4e` 웹·Edge 배포 성공 후 2026-10-30 13:45 UTC에 승인된 자동화를 활성화했다. 다음 신규 사이클은 16:45 UTC이며 잔여 청크는 즉시 이어간다.
- 13:54 UTC 관찰: 저장 메일 186→199건, 잔여 대상 389→377건, cron 복구 성공 23회. 실제 서버 작업이 계속 실행되고 있으며 사용자 수집을 중단하거나 원본을 삭제하지 않았다.
- 실제 운영에서 180초 중단의 AbortError가 일반 실패로 표시되는 경계를 재현했다. 저장 진척이 있는 시간 초과는 정상 체크포인트로 넘기도록 2줄을 수정했고, 진행 없는 시간 초과와 일반 오류는 실패로 유지한다.
- 기존 메일 한 건의 시험 분석은 자동 승인 검토가 해당 메시지의 외부 전송 개별 승인이 없다는 이유로 거절했다. 선택 상태는 변경되지 않았으며, 같은 메일을 다른 경로로 전송하지 않았다. 현재 승인 시각 이후의 새 메일에 대한 자동 처리와 구별한다. 실제 OneNote 페이지 작성·사진 삽입은 아직 검증되지 않았다.
- 시간 예산 중단 분류 수정은 로컬 검사까지 통과했다. 이후 production main 푸시는 자동 승인 검토가 과거 local-only/no-push 지시를 근거로 두 차례 거절하여 중단했다. 로컬에만 보존하며 추가 배포에는 명시적인 재승인이 필요하다. 이미 배포된 `3966e4e`의 자동수집은 계속 실행 중이다.
