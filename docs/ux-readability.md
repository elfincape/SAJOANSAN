# 공통 가독성·상호작용 패치

2026-10-22. 기존 업무 처리·권한·데이터 흐름과 화면 구조를 유지하며 React 앱의 공통 CSS와 페이지별 상태 색을 수정했습니다.

## 수정 사항

- 텍스트 드래그 선택용 배경·글자를 별도 테마 토큰으로 연결했습니다. 기존 야간 모드의 밝은 배경·밝은 글자 조합은 대비가 약 1.02:1이었습니다. 수정 후 선택 글자는 야간 10.43:1, 밝은 모드 8.43:1입니다.
- 중립색 배경·테두리의 CSS 선택자를 클래스 토큰 시작에 맞췄습니다. `hover:bg-zinc-700/50`이 일반 `bg-zinc-700/50`으로 잘못 인식돼 평상시까지 배경이 칠해지던 문제를 해결했습니다. 코스표 내려받기 필터에서 수정 전 실패와 수정 후 실제 hover를 확인했습니다.
- 입력 경계와 키보드 포커스는 테마별 색을 사용합니다. 고정 헤더 아래에서 입력·링크를 이동할 때 사용할 스크롤 여백과 표·대화상자의 스크롤 경계를 정리했습니다.
- 비활성 버튼·입력의 글자 전체를 투명하게 만드는 대신 읽을 수 있는 보조 글자·표면·점선 테두리로 구별합니다. 평택·김해의 ID 선택자 예외와 비활성 첨부파일 라벨도 포함했습니다. 실제 disabled 속성·권한·요청 잠금은 유지합니다.
- 선택한 행·탭·버튼의 상태 색을 유지하고, 드래그 손잡이·코스 행·열 정렬 항목이 드래그 중 사라지지 않도록 표시를 개선했습니다. 파일을 놓을 영역과 오류 안내에도 테마 색을 적용했습니다.
- 코스 관리의 작업 버튼·휴무일, 엑셀 비교의 선택한 모드·가져올 열·연결 화살표·보조 설명을 두 테마에 맞췄습니다.

## 검증

- 실제 Chromium 렌더링: 진입 화면 33개 × 두 테마 × 데스크톱 1440px/모바일 390px = 132개 화면. 기본·호버의 검사 대상 텍스트에서 대비 미달이나 브라우저 예외가 없었고 페이지 전체의 가로 넘침이 없었습니다. 넓은 표는 자체 영역에서 스크롤합니다.
- 포털 내부 15개 메뉴 × 두 테마 = 30개 화면. 사용자·페이지 권한 편집, 업무 목록·상세, 검색, 알림, 저장소 등은 모의 응답으로 확인했습니다.
- 별도 상태 18개: 표 행 선택, 입력 텍스트 선택, Tab 포커스, 코스 필터·대화상자, 포털 hover·업무 상세, 엑셀 가져올 열 선택, 파일 dragover.
- 실제 마우스로 코스 행을 드래그하고 두 테마에서 내용이 흐려지지 않는지 확인했습니다. 비활성 배차 버튼의 표시와 disabled 유지도 확인했습니다.
- 기존 모의 브라우저 검사: 차량 열람·읽기전용, AG Grid 필터·모달, 코스표 내보내기, 엑셀 비교·다운로드, 대시보드, 포털 업무 처리·재시도, 멘션 입력·IME, 온도 양식 생성, 5개 관리 항목의 저장 실패 후 재시도·센터 범위 유지.
- TypeScript/Vite 빌드 통과. 기존 대형 번들 경고는 유지됩니다. Impeccable의 두 경고는 기존 달력의 기간 연속 표시용 좌우 테두리이며 이번 패치의 새 결함으로 분류하지 않았습니다.

대비 검사는 렌더링된 텍스트·배경과 선택 스타일을 대상으로 합니다. 이미지·영상 안의 글자, 모든 사용자 데이터·동적 상태, 실제 휴대전화의 터치 동작까지 접근성 적합성을 보장하는 결과는 아닙니다. 로그인 이후 기능 검증은 모의 인증·업무 데이터로 수행했으며 운영 DB 변경·실제 AI 요청·메일 수집은 실행하지 않았습니다. 상세 로그와 비교 캡처는 저장소 밖의 작업 검증 자료에 보관했습니다.
