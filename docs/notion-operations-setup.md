# 거점 운영관리 구성

기존 안산센터 업무보드·평택센터 업무보드 팀스페이스 안에서 페이지별로 정리했습니다. 팀스페이스 필터 검색 및 페이지의 상위 경로로 배치를 확인했습니다.

## 센터별 화면

안산 업무 메뉴 아래 일일보고·기사 서류 관리·납품처 정보 확인·거점 특이사항·이배송 관리 5개 페이지를 둡니다.
평택 업무 메뉴 아래 일일보고·기사 서류 관리·납품처 정보 확인·거점 특이사항 4개 페이지를 둡니다.

기존 한 화면에 펼쳐진 목록은 제거하고 첫 화면에는 페이지 선택 메뉴만 둡니다. 기존 연결 DB를 새 업무 페이지로 이동해 필터와 원본 데이터 소스 ID를 유지했습니다. 기사 서류 페이지에는 전체 서류 목록과 기존 보건증 갱신 목록을 함께 둡니다.

## 사용 가능

일일보고·특이사항 작성, 센터별 기존 보건증 갱신 목록 조회.

## 남은 작업

HQ 원본 DB 배치, 그룹 접근 권한, 새 DB 내부 연결 등록, 기사 서류 전체 목록 동기화, 납품처 양방향 입력, 안산 이배송 양방향 입력·사진 전송·동시 수정 충돌 처리는 아직 미완료입니다. 센터 필터는 접근 권한을 대신하지 않습니다.

연결 정보는 notion-operations-setup.json에 저장합니다. 비밀값은 포함하지 않습니다.
