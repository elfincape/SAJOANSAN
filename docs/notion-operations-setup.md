# 거점 운영관리 구성

Notion DB와 센터별 화면을 생성했습니다. 일일보고·특이사항은 작성 가능하며 기존 보건증 목록은 센터별 연결 보기로 표시합니다.

## 배치

- 거점 운영관리 페이지: HQ에 배치 예정
- 안산센터 업무 홈: 안산센터 업무보드 팀스페이스에 배치 예정
- 평택센터 업무 홈: 평택센터 업무보드 팀스페이스에 배치 예정

현재 페이지들은 비공개 초안입니다. 팀스페이스 배치·그룹 권한은 아직 적용하지 않았습니다. 필터는 접근 권한을 대신하지 않습니다.

## 연결 준비

거점 운영관리 페이지에 내부 연결 `SAJOANSAN 웹 연동`을 등록해야 서버가 새 데이터 소스를 읽고 쓸 수 있습니다. ChatGPT Notion 연결과 내부 웹 연결은 별도 권한입니다.

## 남은 구현

기사 서류 전체 목록 동기화, 납품처 양방향 입력, 안산 이배송 양방향 입력·사진 전송·동시 수정 충돌 처리는 미구현입니다. 웹으로 쓰는 변경은 아직 활성화하지 않았습니다.

데이터 소스 ID와 페이지 ID는 `notion-operations-setup.json`에 저장합니다. 비밀값은 포함하지 않습니다.
