## 변경

1. `WorkspaceProvider` 마지막 공통 스타일로 `frosted-surfaces.css`를 연결했다. 관리허브·대시보드·포털·관리 도구·임베디드 페이지가 같은 재질 토큰을 사용한다.
2. 장식 테두리·표 구분선을 투명화하고 유백색/차콜 표면, 입력창 농도, 여백과 행 강조로 구분한다. 상태색·선택·오류·키보드 포커스는 별도로 유지한다.
3. 표 헤더는 불투명하게, 글자·숫자는 블러 없이 유지한다. 표와 입력 숫자는 tabular-nums를 사용한다. 실시간 배경 블러는 헤더·사이드바·떠 있는 팝업에 한정한다.
4. 공통 `Modal`의 별도 애니메이션 표면도 팝업 토큰을 사용하도록 수정했다. 투명한 외곽 컨테이너에 블러를 중첩하지 않는다. 기존 Radix 포커스·닫기·Motion 동작을 유지한다.
5. 톡클라우드 iframe은 부모의 공통 표면·호버·오류·포커스 토큰을 전달받는다. QR·삭제·진행 처리 로직은 변경하지 않는다.
6. `DESIGN.md`의 이전 선/테두리 규칙을 새 승인 기준으로 갱신했다. 고대비·투명도 감소 설정과 원본 Excel/PDF·인쇄 경계는 예외로 보존한다.

## 검수

- `node app/node_modules/typescript/bin/tsc -b app`: 통과.
- `node node_modules/vite/bin/vite.js build` (app): 통과. 기존 PGlite browser externalization/eval 및 큰 청크 경고가 남는다.
- `node --check tools/talkcloud-manager/public/app.js`, Prettier, `git diff --check`: 통과.
- Impeccable detect: 변경 표면/공통 컴포넌트/iframe 스타일에서 발견 사항 0건.
- Ego Lite 기존 실제 로그인으로 페이지를 읽기 순회했다. 배포 전에는 운영 DOM에 변경 CSS를 일시 적용해 비교했다. 이것을 운영 배포 완료로 계산하지 않는다.
- 양쪽 테마 확인: 허브, 대시보드, 코스 목록과 실제 코스 편집, 납품처·기사·차량·운수사·사용자, 직원별 권한, 센터 업무, 운영 업무, 일일정리, 김해 배차, 평택 용차, 1탑2실 작업·템플릿, 배차 파서, 파레트, 엑셀 비교, PDF, 기울기 보정, 하불, 안산김해부산안산, 두 거리계산, 설정·이력·코스표 출력·가져오기·이배송·쿠팡·톡클라우드 진입 화면.
- 확인한 뷰포트에서 문서 가로 넘침과 본문/표 셀의 `filter: blur`는 없었다. 표 자체의 필요한 가로 스크롤은 유지한다.
- 동일 대시보드 자료의 납품처 팝업을 열어 전후 비교하고 저장 없이 닫았다. Pretendard 로딩, 본문 무블러, 키보드 포커스를 확인했다. 실제 업무값·권한을 시험 저장하지 않았다.
- 대표 토큰 대비 계산: 라이트 본문 13.81:1·보조 5.63:1, 다크 중첩 입력 표면에서 본문 7.86:1·보조 4.55:1. 모든 가능한 업무 상태의 픽셀 대비를 전수 보장하는 수치는 아니다.
- 한계: 평택 가배차와 폐기된 Notion 경로는 현재 계정의 접근 거절 팝업까지만 확인했다. 로그인 경로는 이미 로그인된 세션 때문에 센터 선택으로 이동하여 로그인 폼의 실제 검증은 미실시다. 파일 업로드/분석 후에만 나타나는 모든 결과·오류 팝업을 실제 업무 자료로 생성하지 않았다. 공통 컴포넌트와 스타일 적용 범위에 포함되지만 모든 업무 상태의 실행 검증과 구분한다.

## 변경 영향 검토

수정 파일은 공통 CSS, CSS import, 모달 표면 값, iframe 테마 변수 전달, 디자인/검수 문서다. 인증·권한·API 저장·DB·외부 요청 자격·동작 핸들러 변경이 없다. UI 영향 범위는 모든 공통 작업 화면이며, 의미 있는 행 색과 오류·포커스는 제거하지 않는다. 변경부 검토에서 보안 회귀 발견 사항은 없으며 위험도는 낮다. 전체 기능 회귀나 보안 전면 감사를 수행한 결과는 아니다.
