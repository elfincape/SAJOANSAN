## 복구
현재값을 먼저 보관하고 after.json의 updated_at과 적용 필드가 일치하는 행에 한해 full-backup.json의 해당 필드만 복구한다. 이후 사용자가 변경한 행은 충돌로 보류한다. 전체 DB·납품처 행·route_stops를 과거 사본으로 덮어쓰지 않는다.
프런트는 직전 운영 커밋으로 되돌릴 수 있으며 추가 컬럼은 유지해 데이터 손실을 막는다. 시작·조건 컬럼 삭제나 course_view 교체를 자동 수행하지 않는다.
