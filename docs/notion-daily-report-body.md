# 일일보고

센터 일일보고 페이지에 날짜별 문서 제목만 직접 표시합니다. 연·월 페이지를 거치지 않습니다. 센터 필터와 보고일 내림차순을 유지합니다. 문서를 열어 아래 본문 양식에 업무별로 한 줄씩 작성합니다.

## 주요업무
- [ ] 업무 입력
- [ ] 업무 입력
- [ ] 업무 입력
## 미처리업무
- [ ] 업무 입력 · 담당자 · 기한
- [ ] 업무 입력 · 담당자 · 기한
- [ ] 업무 입력 · 담당자 · 기한
## 익일 계획
- [ ] 업무 입력
- [ ] 업무 입력
- [ ] 업무 입력

기존 보고서 4개에는 본문 양식을 삽입했습니다. 보고 상태 및 세 가지 업무 텍스트 속성은 제거했습니다. 제목 속성은 문서입니다.

## 남은 설정

새로 만들기에 기본 본문 양식을 자동 적용하는 Notion DB 템플릿 설정은 미완료입니다. 연결 도구에서 기본 DB 템플릿 생성·선택을 지원하지 않으며 브라우저 제어 초기화에 오류가 발생했습니다. 복사 방식은 사용자가 원하는 최종 작성 방식이 아닙니다. Notion UI에서 일일보고 템플릿을 생성하고 각 센터의 목록 보기 기본값으로 지정해야 합니다.

이전 연·월 구성 및 별도 양식 페이지는 거점 운영관리의 이전 일일보고 구성 아래로 옮겨 센터 작성 화면에서 제거했습니다.
