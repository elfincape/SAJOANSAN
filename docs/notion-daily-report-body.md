# 일일보고 본문

업무는 가로 속성 대신 보고서 본문에 저장합니다. `주요업무`, `미처리업무`, `익일 계획` 아래에 업무별 체크박스를 한 줄씩 추가합니다.

보고 상태 속성은 제거했습니다. Notion의 필수 제목 속성은 `문서`로 변경했으며 날짜를 문서 제목으로 사용할 수 있습니다. 목록은 문서 제목만 표시합니다. 보고일과 작성자는 문서 상단, 나머지 관리 속성은 사이드바에 있습니다.

두 센터의 일일보고 폴더에 작성 양식을 배치했습니다. 새 보고서는 작성 양식의 본문을 복사합니다. 기본 DB 템플릿 자동 적용은 설정하지 않았습니다.
